Place your optional bundled focus-music tracks in this folder.

Expected filenames:
- rain.mp3
- white-noise.mp3
- ocean.mp3
- cafe.mp3
- library.mp3
- keyboard.mp3
- piano.mp3
- lofi.mp3

The app currently works without these files by falling back to generated
ambient sound. If you add real MP3 files here later, you can switch the
player back to prefer bundled audio first.
